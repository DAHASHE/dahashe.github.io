ما الذي يفعله OctaWhat Octa does

ستة أدوات في تطبيق واحد، وكل أداة تفتح من نفس المشروع.Six tools in one app, all opening from the same project.

مدير الملفاتFile manager

تصفّح المجلدات، وصفّ حسب التطبيقات والصور والفيديو والصوت والمستندات. ابحث بالاسم أو داخل المحتوى، وأنشئ ملفًا أو مجلدًا أو صورة جديدة.Browse folders and filter by apps, images, video, audio and documents. Search by name or content, and create new files, folders or images.

محرر الأكوادCode editor

تلوين للصياغة وترقيم للأسطر وتبويبات لـ HTML وJS وPython. زر تشغيل يعرض صفحتك فورًا، وعند فتح الملف تظهر لك أدوات الحجم والتنسيق والتراجع.Syntax colors, line numbers and tabs for HTML, JS and Python. A run button previews your page instantly, with tools for font size, formatting and undo.

المساعد الذكيAI assistant

يفهم هيكل مجلدك ويقترح عليك ما يمكن فعله، مثل تنظيم الكاميرا أو ضغط الصور. وضع الطيار الآلي ينفّذ القراءة والكتابة والنقل بلا سؤال، ووضع الخطة يعمل ضمن حدود ما تطلبه. وتستطيع إضافة نماذجك الخاصة.It understands your folder structure and suggests actions like organizing your camera folder or compressing images. Autopilot reads, writes and moves without asking; Plan mode stays within what you request. You can add your own models.

لوحة الرسمDrawing canvas

لوحة بطبقات وفرشاة وقلم وعجلة لونية. اختر مقاس A4 أو مربعًا أو 16:9، بخلفية بيضاء أو شفافة، واحفظ بصيغة PNG أو BMP.A layered canvas with brush, pen and a color dial. Pick A4, square or 16:9, white or transparent background, and save as PNG or BMP.

المشاركة عبر Wi-FiWi-Fi sharing

رمز QR ورابط محلي، وأي جهاز على نفس الشبكة يفتح ملفاتك. كلمة المرور اختيارية، لكن ننصح بها.A QR code and a local link: any device on the same network can open your files. The password is optional, but we recommend one.

بث صفحة ويبBroadcast a web page

اختر الصفحات التي تريدها فقط، وسيرى الآخرون ما تصل إليه هذه الصفحات لا أكثر. الطرفية مدمجة أيضًا لمن يحتاجها.Choose only the pages you want; viewers see what those pages reach and nothing more. A built-in terminal is there when you need it.

أرسل ملفاتك في ثلاث خطواتSend files in three steps

http://share.local:4747/your-session
  1. اضغط الزر المركزي ثم «مشاركة وبث».Tap the central button, then “Share & broadcast”.
  2. امسح الرمز من الجهاز الآخر أو افتح الرابط.Scan the code on the other device, or open the link.
  3. أنهِ الجلسة حين تنتهي، فيُغلق الرابط فورًا.End the session when you’re done and the link closes at once.
